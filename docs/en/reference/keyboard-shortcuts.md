# Keyboard shortcuts

These are the keys Initiative listens for, grouped by where you are when you press them. If you only ever learn one, make it search, because nothing else comes close.

## Everywhere

| Action | Mac | Windows / Linux |
|---|---|---|
| Open or close search | ++cmd+k++ | ++ctrl+k++ |
| Show or hide the sidebar | ++cmd+b++ | ++ctrl+b++ |
| Close a dialog, a menu or search | ++esc++ | ++esc++ |

On a touchscreen, tap with three fingers to open search.

## In search

| Action | Key |
|---|---|
| Switch between **Tools**, **Members**, **Comments** and **Tags** while you type | ++tab++ |
| Move through the results | ++arrow-up++ ++arrow-down++ |
| Open the highlighted result | ++enter++ |

More on what search finds is in [Search & shortcuts](../guides/search-and-shortcuts.md).

## Writing comments and descriptions

| Action | Mac | Windows / Linux |
|---|---|---|
| Post a comment | ++cmd+enter++ | ++ctrl+enter++ |
| Save a description you're editing | ++cmd+enter++ | ++ctrl+enter++ |
| Save a one-line field, such as a name | ++enter++ | ++enter++ |
| Put a field back the way it was | ++esc++ | ++esc++ |
| Send a question from **Help**, or feedback | ++cmd+enter++ | ++ctrl+enter++ |

In a comment, pressing ++enter++ on a bulleted or numbered line starts the next item for you.

## Writing in documents, wiki pages and posts

| Type | To |
|---|---|
| `/` | Open the insert menu: headings, tables, checklists, pictures, drawings and more |
| `@` | Mention a person |
| `#` | Link to something in the initiative |
| `[[` | Link to a tool, or make one that doesn't exist yet |
| `:` | Pick an emoji |

Markdown turns into formatting as you type it, so `# ` makes a heading, `- ` starts a list and `**bold**` comes out bold. In a text document you can edit, ++cmd+s++ or ++ctrl+s++ saves straight away, though it saves on its own as you go. [Mentions & links](../guides/mentions-and-links.md) has more on `@`, `#` and `[[`, which work in comments too.

## In messages

| Action | Key |
|---|---|
| Send | ++enter++ |
| Start a new line | ++shift+enter++ |
| Stop replying or editing | ++esc++ |

## In a project

When you're not typing in a field, ++enter++ opens the box for a new task, as long as you can add tasks to the project.

### In the Gantt view

Click a row first, or move to the chart with ++tab++.

| Action | Mac | Windows / Linux |
|---|---|---|
| Move between rows | ++arrow-up++ ++arrow-down++ | ++arrow-up++ ++arrow-down++ |
| Jump to the first or last row | ++home++ ++end++ | ++home++ ++end++ |
| Show a task's parts, then step into them | ++arrow-right++ | ++arrow-right++ |
| Hide a task's parts, or go up to the task it's part of | ++arrow-left++ | ++arrow-left++ |
| Open the task | ++enter++ | ++enter++ |
| Move the task a day earlier or later | ++option+arrow-left++ ++option+arrow-right++ | ++alt+arrow-left++ ++alt+arrow-right++ |
| Make the task end a day earlier or later | ++option+shift+arrow-left++ ++option+shift+arrow-right++ | ++alt+shift+arrow-left++ ++alt+shift+arrow-right++ |

A task with no dates starts today the first time you move it. Moves save once you stop pressing.

## In a spreadsheet

These work in a spreadsheet you can edit.

| Action | Mac | Windows / Linux |
|---|---|---|
| Move between cells | Arrow keys | Arrow keys |
| Select as you move | ++shift++ and an arrow | ++shift++ and an arrow |
| Jump to the edge of the data | ++cmd++ and an arrow | ++ctrl++ and an arrow |
| Go to the start of the row, or to the first cell | ++home++, ++cmd+home++ | ++home++, ++ctrl+home++ |
| Go to the end of the row's data, or to the last cell with data | ++end++, ++cmd+end++ | ++end++, ++ctrl+end++ |
| Edit a cell | ++enter++, ++f2++, or start typing | ++enter++, ++f2++, or start typing |
| Finish editing and move down | ++enter++ | ++enter++ |
| Finish editing and move right, or left | ++tab++, ++shift+tab++ | ++tab++, ++shift+tab++ |
| Stop editing without saving the change | ++esc++ | ++esc++ |
| Clear the selected cells | ++delete++ or ++backspace++ | ++delete++ or ++backspace++ |
| Cut, copy, paste | ++cmd+x++ ++cmd+c++ ++cmd+v++ | ++ctrl+x++ ++ctrl+c++ ++ctrl+v++ |
| Undo | ++cmd+z++ | ++ctrl+z++ |
| Redo | ++cmd+shift+z++ | ++ctrl+y++ or ++ctrl+shift+z++ |
| Find and replace | ++cmd+f++ | ++ctrl+f++ |
| Next or previous match, in the find bar | ++enter++, ++shift+enter++ | ++enter++, ++shift+enter++ |

## On a whiteboard

Whiteboards come with a full set of drawing keys of their own. Press `?` on one to list them.

## Picking several things in a list

This works the same in a tool's **Grid**, **List** and **Tags** views. To act on several things at once, open **More actions** (the ⋯ button) and choose **Select items**.

| Action | How |
|---|---|
| Select one | Click it |
| Select everything between two | Click the first, then hold ++shift++ and click the last |
| Clear everything between two | Untick one, then hold ++shift++ and click the last |
| Do either from the keyboard | ++shift+enter++ or ++shift+space++ on the last one |

## Moving things around without a mouse

Some lists you can drag into your own order also move from the keyboard: the communities on the rail, the cards in a tool's list when you've put them in your own order, a wiki's pages, and the outline in the layout editor. Move to the item (or its grip) with ++tab++ first.

| Action | Key |
|---|---|
| Pick it up | ++space++ or ++enter++ |
| Move it | Arrow keys |
| Put it down | ++space++ or ++enter++ |
| Put it back where it was | ++esc++ |

In the layout editor, ++cmd+z++ or ++ctrl+z++ undoes a change and ++cmd+shift+z++ or ++ctrl+shift+z++ redoes it, whenever you're not typing in a field.

## Looking at pictures

When a picture is open full size:

| Action | Key |
|---|---|
| Previous or next picture | ++arrow-left++ ++arrow-right++ |
| Zoom in | ++"+"++ |
| Zoom out | ++"-"++ |
| Back to normal size | ++0++ |
| Close | ++esc++ |
