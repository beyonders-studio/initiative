# Tools

Everything that lives inside an initiative is a **tool**: a project, a file, a calendar and so on. A new initiative starts with projects and files switched on, and the rest wait quietly, entirely unbothered by whether you ever open them.

Most groups run on projects and files for a good long while, and there's nothing wrong with that. The others each have a fairly specific moment when you'll suddenly want them:

- A **calendar**, when scheduling has visibly outgrown the group chat.
- **Counters**, when a number needs to be the same number for everyone in the room.
- A **dashboard**, when somebody who isn't doing the work starts asking how the work is going.
- **Posts**, the third time something important was announced in a chat and missed by four people.
- A **wiki**, when every answer to "how does the float work?" is "ask Margaret".
- **Contacts**, when the florist's number lives in three people's phones and all three of them are at the wedding.

Every tool works the same way in the places this page covers: making one, finding it, sharing it, copying it and putting it away. Learn it once and it's true of the next one.

## Turn a tool on or off for an initiative

The initiative's managers and community admins can do this. If you can't, ask one of them.

1. Open the initiative and select **Initiative settings**.
2. On the **Details** tab, find the **Tools** card.
3. Switch the tool on or off.
4. Turning one on asks who should see it: **Everyone in this initiative**, or **Managers only, for now** while you set it up. Pick one and select **Turn it on**.
5. Turning one off asks you to confirm with **Turn it off**.

Turning a tool off hides it from everyone, managers included, and deletes nothing. Turn it back on and it's all still there. That goes for projects and files too, so a book club that only keeps notes and a reading schedule can switch projects off rather than look at an empty tab forever.

Each switched-on tool's card says which roles can see it. **Give it to everyone** hands it to every role, and **Manage roles** opens the roles for finer choices. If a switch can't be changed, your community sets that tool for every initiative.

Making an initiative asks which tools it starts with, too. See [Initiatives](initiatives.md).

## Who can see which tools

Two separate things decide it, and it helps to know which one you're up against.

- **Your role** in the initiative decides which kinds of tool you can see and make. Each tool has a **View** and a **Create** switch on the initiative's roles. See [Initiative roles](../sharing/initiative-roles.md).
- **Sharing** decides which ones of that kind you can reach, as a **Viewer** or an **Editor**. Every tool has one owner. See [Sharing](../sharing/sharing-projects-and-files.md).

So "I can't see Dashboards at all" is a role question, for an initiative manager, and "I can see Dashboards but not that dashboard" is a sharing question, for whoever owns it. Knowing which saves you asking the wrong person.

## Make a new one

You need a role that can create that kind of tool. If the button isn't there, ask one of the initiative's managers.

1. Open the initiative and select the tool's tab, such as **Dashboards**.
2. Select the create button: **Add Project**, **New file**, **Create Counter Group**, **New Dashboard**, **New Post**, **New Wiki** or **New contact**. On the **Calendar** tab, it's **New Calendar** in the list of calendars. On a phone, it's the **+** at the bottom of the screen.
3. Type a **Name**, and a description if you like.
4. To change who can see it, open **Advanced options**. Everyone in the initiative can view it unless you say otherwise.
5. Select the create button at the bottom of the dialog.

It opens straight away, and you're its owner. Each tool's own page covers anything extra its dialog asks for, such as a project's template.

## Find things in a tool's list { #lists }

Each tool's tab on the initiative's page lists everything of that kind you can reach.

- **View** switches between **Grid** (cards side by side), **List** (one row each, quicker to scan when there are lots) and **Tags** (the [tag](tags.md) tree beside the cards, or a row of tag chips on a phone). Select a tag to see what carries it, and ++ctrl++-click more tags (++cmd++-click on a Mac) to add them. A tag includes the tags filed under it.
- **Show** switches between **Active** and **Archived**, and for projects and files **Templates** too, each with how many are in it.
- **Filters** narrows the list by name, by tag and by the initiative's [metadata](initiatives.md#metadata). **Clear all** takes the filters off.

Your view and filters are remembered for each tool in each initiative, and they're yours alone. Some cards show what's inside without opening anything: a dashboard's card is a small copy of the dashboard, and a counter group's shows its first few counters.

## Change several at once

1. On the tool's tab, open **More actions** (the **…**) and select **Select items**.
2. Select the first one you want. Hold ++shift++ and select another to take everything in between.
3. In the bar that appears, choose **Export**, **Edit tags**, **Duplicate**, **Delete** or **Edit access**. Files also offer **Add to collection**.
4. Select **Cancel** when you're done.

You need edit access to everything you've picked to change it, and you can only delete things you own. **Edit access** adds or removes a role's access on all of them at once.

## Bring back something you exported

1. On the tool's tab, open **More actions** and select **Import from file**.
2. Choose the file you exported.
3. Under **Import into**, pick the initiative.
4. Select **Import**.

People in the file are matched by their handle. Anyone who can't be matched, or can't be added to that initiative, is listed so you know who to sort out by hand.

## Get a ready-made one from the marketplace

Projects and dashboards can come ready-made. On the **Projects** or **Dashboards** tab, open **More actions** and select **Browse the marketplace**. What you add becomes an ordinary project or dashboard of yours. See [Plug-ins & the marketplace](plugins-and-marketplace.md).

## The top of a tool's page { #the-top-of-every-tool-page }

Open a project, a dashboard or most other tools and the top of the page is laid out the same way.

- **A band in the initiative's color**, so you always know which initiative you're standing in. It holds the way back to the list, and **Settings** across from it if you can change things. If you can only read it, **Ask to edit** is there instead.
- **The name and description.** Select the name to rename it (files and calendars are renamed elsewhere). The bookmark beside it adds it to your [Bookmarks](your-space.md#bookmarks), and the bell beside that [subscribes](your-space.md#subscribing) you to it.
- **A strip underneath**, starting with **Status** (**Active** or **Archived**, plus **Template** for projects and files), then whatever only this tool has (a project's progress and dates), then **Tags** and **Metadata**. You can change them right there.

A wiki and a calendar are laid out differently. See [Wikis](wikis.md) and [Calendar](calendar.md).

## Change a tool's settings

Select **Settings** at the top of the tool's page. You need edit access; the **Access** tab is the owner's to change.

| Tab | What's on it |
|---|---|
| **Details** | The name and description, **Template** (projects and files), **Tags**, **Metadata** and **Comments**. |
| **Access** | Who can see and edit it. See [Sharing](../sharing/sharing-projects-and-files.md). |
| **Layouts** | Projects and counter groups only. See [Layouts](layouts.md). |
| The tool's own tabs | A project's **Task statuses**, **Task types** and **Properties**, for instance. |
| **Advanced** | **Duplicate**, **Export**, **Archive** and the **Danger Zone**. |

### Turn comments off

1. Open **Settings** and stay on **Details**.
2. Under **Comments**, switch off **Enable comments**.

Everything already posted is kept, and it comes back when you switch comments on again. A wiki has no switch of its own, because its pages carry the conversations.

## Duplicate a tool { #duplicating }

Every tool but a post can be copied.

1. Open **Settings** and select **Advanced**.
2. Under **Duplicate**, select **Duplicate**.
3. Pick the **Initiative** it goes into. You can choose any initiative where you can make that kind of tool.
4. Change the **Name** if you like. It starts as the original's name with "(Copy)" after it.
5. Select **Duplicate**.

The copy brings everything inside it, with tags and links: a project its tasks, a calendar its events and repeats, a wiki its published pages. It keeps its sharing while it stays in the same initiative, and metadata values only carry over within the same initiative too. Anyone who can read a template can copy it. An initiative set to keep its content in won't copy anything out to another initiative.

A post is published once, and the next one is a new post. The things inside a tool (a task, a counter, an event, a wiki page) copy on their own as well, with "(Copy)" on the name; each tool's page says where.

## Export a tool

Only a tool's owner can export it.

1. Open **Settings** and select **Advanced**.
2. Under **Export**, pick a format.

Each tool offers an **Importable file** you can bring back in with **Import from file**, here or on another server, and most offer a report or two as well, like a PDF or a spreadsheet. An initiative set to keep its content in turns exporting off.

## Archive a tool

Archiving marks a thing finished. It, and everything inside it, turns read-only until you take it back out. You need edit access.

Choose **Archived** under **Status** at the top of its page, or open **Settings**, select **Advanced** and select **Archive**. It moves to **Archived** under **Show** on the tool's tab, and **Unarchive** in the same places brings it back.

## Delete a tool

Only a tool's owner can delete it.

1. Open **Settings** and select **Advanced**.
2. Under **Danger Zone**, select **Delete**.
3. Select **Delete** again to confirm.

It goes to the trash, where it can be restored until the community's retention period runs out. See [Trash](../account/profile-and-preferences.md#trash).

## See what changed

On a big screen, a tool's page has **Activity** folded down its right-hand edge. Open it and you get a card for each item other people touched this week, saying what happened (created, edited, moved, completed, commented on, rescheduled), who did it and when. An initiative's own page has one too, for the whole initiative. It closes again when you've seen enough, which is usually about four cards in.

## Link a tool to other things

Almost every tool, and most of what's inside one, has a **Connections** section. It lists what this links to and what links to it, and it's where you say how two things relate: this task is blocked by that one, this file is attached to that project. See [Mentions & links](mentions-and-links.md#connections).

Everything here also turns up in [My Tools](your-space.md#my-tools), gathered with everything else of its kind from every community you're in.
